3D computation time scaling with truncation order N

Source: Table 4.1 (chap-1-4.tex, \label{tab:md3D_calculationTime}) and Fig. 4.1 (\label{fig:md3D_speed}), § "Tests et validation" > "Durée du calcul", p.~94

Performance test (not a cross-method comparison): measured wall-clock time of the 3D differential method as a function of N = N_x = N_y. Matrix sizes scale with (2N_x+1)(2N_y+1), and the dominant cost is matrix-matrix products/inversions (cost ~ cube of the matrix size), so the time is expected — and observed — to scale as N^6.
