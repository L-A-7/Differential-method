1Organising a study

  • Use one folder per study, holding the parameter file, the structure file and a script. Run the programs from that folder, since results are written to the current directory.
  • Keep the parameter file for what does not change and give what varies on the command line. Build profile_name from the varying values: it names the result file, it may contain a sub-folder (-profile_name scan/theta_30), and a run overwrites an existing file of the same name.
  • Start from a validated case in thesis_validation_cases/ that resembles your structure. Its param.txt is known to work.

2Scanning a parameter

One run per value, then one pass to collect the results. The example scans the angle of incidence for the aluminium grating of the manual's first run.

#!/bin/sh
# scan.sh - angle scan, results in scan/theta_<angle>.txt
MD2D=${MD2D:-$HOME/DifferentialMethod/md2D/md2D}
mkdir -p scan
for t in 0 10 20 30 40; do
    "$MD2D" -param tayeb_alu.txt -theta_i $t -verbosity 0 -profile_name scan/theta_$t
done
# collect.py - one line per angle
import sys; sys.path.insert(0, "/path/to/DifferentialMethod/thesis_validation_cases/tools")
from mdres import eff          # eff(file, "r"|"t", n) for md2D, eff(file, "r"|"t", nx, ny) for md3D
for t in (0, 10, 20, 30, 40):
    f = "scan/theta_%d.txt" % t
    print(t, eff(f, "r", 0), eff(f, "r", -1))

An order that is evanescent at some angle returns None. Wavelength scans work the same way with -lambda. If the indices change with wavelength, pass them too: -n_sub_re … -n_sub_im … (md2D) or -nu_sub_re … -nu_sub_im … (md3D). Independent runs can go in parallel (& and wait, or GNU parallel), one per core.

3Checking convergence

Do this once per new kind of structure, on the most demanding configuration: the largest angle, the shortest wavelength and TM polarisation.

for NS in 250 500 1000 2000; do md2D -param p.txt -NS $NS -verbosity 0 -profile_name conv/NS$NS; done
for N  in 20 30 40 60;       do md2D -param p.txt -N  $N  -verbosity 0 -profile_name conv/N$N;   done
grep -H one_minus_sum_eff conv/*.txt
  • one_minus_sum_eff tracks the NS convergence for lossless structures, but not the N convergence. Compare the efficiencies you need between successive N.
  • Typical outcome: dielectric gratings converge with slices of λ/100–λ/1000 and N just above the number of propagating orders. Metals in TM need slices of λ/1000 or finer and N of 30–50.

4Lamellar gratings and stacks

Binary structures (vertical walls, flat tops) are best described as a stack (MULTICOUCHES) and computed with calcul_method = Z_INVAR. Each z-invariant layer is then propagated exactly, like RCWA, and a few slices suffice.

# line of material n1 (width 40 % of the period) on the substrate
utils/profilGen CARRE02_B -L1 0.4 -h1 0.2 -h2 0 -N_profil 1024 > line_raw.txt
{ echo "n1 = 1.46 + i0.0"; cat line_raw.txt; } > line.txt
  • For more materials, add columns (one per interface, top to bottom) and indices n2, n3… (manual § 5). profilGen CARRE03, RECTANGLE04 and TRAPEZ02 write such files.
  • Sloped walls (trapezoids) are no longer z-invariant: use RK4 with enough slices, or Z_INVAR as an explicit staircase approximation in TE only.
  • imposed_S_steps = AUTO (md2D) places the slice boundaries on the horizontal interfaces found in the file, so that no slice straddles one.

5Rough surfaces and non-periodic objects

A non-periodic surface is computed as one period of a large artificial period L. The diffracted orders then sample the scattering diagram with a step Δ(sin θ) = λ/(νL).

utils/profilGen ALEAT01 -N_profil 2048 -Ag 1 -Lg 20 -Ae 0 > rough.txt   # Gaussian-correlated random profile
md2D -param rough_param.txt -L 50.3 -N AUTO -h 0.2 -profile_name rough_TE

The scattered intensity per unit angle (per radian) of each order is

dI/dθ (θn) = (L/λ) ν cos θn en,

with ν the index of the medium where it is observed.

  • N must cover every propagating order: N ≥ (max(ν₁, ν₂) + ν₁|sin θi|)·L/λ, plus a margin. N = AUTO does this. Too small an N silently drops orders while the energy balance still looks perfect. The cost grows as N³, so an L of 50λ means N ≈ 110 and about a minute per run in md2D.
  • Avoid Rayleigh anomalies. If an order is exactly grazing (ν sin θn = ±ν exactly, e.g. L = 50λ at θ = 30°), the results are nan. Shift L or θ slightly (L = 50.3λ).
  • The profile length L must be many correlation lengths long. The heights are rescaled to span h, so set h (peak-to-valley) from the wanted rms and the profile statistics. Average dI/dθ over several random profiles for a smooth diagram.
  • The same approach handles an isolated defect or line: put one object in a large period of flat surface.

6Near-field maps

calcul_type = NEAR_FIELD (md2D) writes the field inside the computation box to the terminal, one row per slice (NS rows of N_x values). A complete example, a copper edge in silicon at 10.6 µm, is in Applications/ExempleUtilisationNearField/.

md2D -param param_snomIR_edges.txt -calcul_type NEAR_FIELD -pola TM -verbosity 0 > field.txt
for c in ReEx ImEx ReEz ImEz ReHpy ImHpy; do utils/lire_tab2 $c < field.txt > $c.txt; done
  • Put h_min / h_max in the structure file to extend the box above and below the structure, so the map includes some air and substrate.
  • The vertical resolution is h/NS and the horizontal one L/N_x. Use Z_INVAR for binary structures: fields near sharp edges are singular and need a large N to resolve.

73D structures and conical incidence

Biperiodic surface

Write an H_XY file from any function z(x,y); md3D computes the normals itself. For example, the pyramid of the validation cases:

python3 thesis_validation_cases/tools/mkprofile.py pyramid pyramid_512x512.txt --n 512
# or, for your own shape:
python3 - <<'EOF'
import math
n = 256
with open("mysurf.txt", "w") as f:
    f.write("profile_type = H_XY\nNprx = %d\nNpry = %d\nprofil =\n" % (n, n))
    for j in range(n):                                   # rows: y
        f.write(" ".join("%.8e" % (math.sin(2*math.pi*i/n) + math.sin(2*math.pi*j/n))
                         for i in range(n)) + "\n")      # columns: x
EOF

Conical incidence on a 1D grating

Use md3D with Ny = 0, a one-row profile (Npry = 1) and any Ly. thesis_validation_cases/case06_conical_incidence_vs_gsolver/ is a complete example (lamellar grating, θ = 30°, φ = 45°, ψ = 45°).

Holes, pillars and other z-invariant patterns

Use an N_XY_ZINVAR index map with calcul_method = Z_INVAR and NS = 1:

python3 thesis_validation_cases/tools/mkprofile.py circle holes.txt --n 1024 --R 0.25 --L 1.0 \
        --n1 "1.0 + i0.0" --n2 "1.75 + i1.5"

Use 512 or more points per side; the 128-point map gives a 3·10⁻⁴ offset. The normal field is radial and centred on the cell, which suits centred round shapes only (manual § 8).

8Material indices

  • Indices go directly into the parameter or structure file as n + ik with k ≥ 0 for absorption. Tabulated data for most materials are at refractiveindex.info.
  • For a wavelength scan, interpolate the table in your script and pass the index on the command line at each step.
  • utils/refractive_index reads material files in a spectroscopic-ellipsometry format (see md2D/Optimization_var_lambda/*_index.txt). Its lookup mode takes the wavelength in nm; the Cauchy mode is currently unreachable (the method argument is ignored).

9Troubleshooting

SymptomCause and fix
ERROR, can't read "fft_filter" (or another key)A required key is missing from the parameter file (manual § 4). Old parameter files lack fft_filter.
can't read "l_smooth" although you do not smoothsmoothing is missing and was left uninitialised. Add smoothing = 0.
nan efficienciesAn order is exactly grazing (Rayleigh anomaly). Change L or θ slightly. With a metal substrate, nan in theta_t is normal.
Efficiencies far above 1 or wildly varying (metal, TM)Too few slices: increase NS until h/NS ≤ λ/1000.
Good energy balance but results change with NNot converged in N; energy conservation cannot detect it. Increase N.
Weak orders off by a few %Structure file too coarse for the number of harmonics. Use more points (≥ 2048 in 2D for N ≈ 100).
Orders appear mirrored (n ↔ −n) compared with another codeDifferent x or angle orientation. Mirror the profile or change the sign of θ.
